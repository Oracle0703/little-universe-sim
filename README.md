# 小宇宙 · 生活正在发生

**游戏公司内部创新评审原型，不是面向玩家的正式产品。** 8 位居民、6 个地点，规则与模板驱动，无人操作也会推进。包含纸条、关系冷暖、计划冲突、传闻、策划热改及评审回放。无 LLM、账号、API Key 或后端。

## 启动与检查

Node **22.12+**（本次验证 24.13.0）、npm。在项目目录执行：

```bash
npm install && npm run dev
```

打开终端地址，默认 http://127.0.0.1:5173/ 。PowerShell 5 请分成两行。首次安装需网络，之后演示不依赖外部服务。

| 命令                   | 用途                                                              |
| ---------------------- | ----------------------------------------------------------------- |
| npm test               | 53 项测试，含连续四天行为回归                                     |
| npm run build          | TypeScript 检查与生产构建                                         |
| npm run preview        | 本地展示 dist，不要直接双击 index.html                            |
| npm run sim:audit      | 真实跑 5760 tick，输出每人心情/工作/用餐/往返，及每日关系与重复度 |
| npm run review:fixture | 按 src/data 重新生成样例局与报告                                  |

## 旁观与纸条

| 操作                       | 结果                                                                                 |
| -------------------------- | ------------------------------------------------------------------------------------ |
| ×1 / ×2 / ×8               | 每现实秒推进 1 / 2 / 8 游戏分钟，可暂停                                              |
| 点地图、名册、事件中的名字 | 看精力/社交/心情满足度（0–100）、目标、作息、关系账本                                |
| 看食堂 / 公园              | 默认各有 2 个稀缺资源；先到先用，排队有心情代价                                      |
| 右侧筛选                   | 全部、生活故事、传闻、冲突、选中居民；原因包含参与者、计划和传播路径                 |
| 塞纸条                     | 每轮一次，临时目标持续 60 游戏分钟；文字仅记录，行为取决于选项；先走完原路段，不瞬移 |
| 重新开局                   | 用当前已应用配置从 D1 11:40 重开并恢复纸条额度；已封存评审局仍可回看                 |
| 5 分钟 Demo                | 真实 advanceWorld 到演示时刻，不注入故事；见 [DEMO.md](./DEMO.md)                    |

关系是同事熟悉度，不是恋爱。直接互动、听闻、自然疏远、策划调整分别记账。新相识默认起点 40，高于默认传闻门槛 35，因此初识也可能转述；可调传闻门槛。

聊天只自主选择有醒着伙伴的位置，并在实际有伴聊天时增加社交；纸条可指定空地点，但独处不产生聊天收益。休息与实际偏好活动可恢复心情，聊天/休息偏好不再陷入零心情死循环。

目标保持按**实际执行时间**计，移动、等位不算活动。一般完成一段活动后再比较目标，继续当前活动有评分加成；纸条、紧急补觉、作息切换、失去聊天伙伴可打断，超时排队可重选。下一段作息开始前，若连一半活动都来不及做完，就不出门，改为就近歇一会儿。

活动带来的心情收益越接近 100 越小（收益 ×（1 − 心情/100）），低落时恢复最快，也不会长期顶满。非作息的可选活动遇到满座会扣分（crowdedResourcePenalty），轮流让位而不是反复排到等位者后面；作息排队（如午饭）不受影响。

久未联系的关系会疏远，但只降到建立时分数的 decayFloorRatio（默认 60%）为止；摩擦等直接互动仍可再往下。

**每日变化：** 从第 2 天起，每人每天的作息整体提前或推后最多 scheduleJitterMinutes（默认 20）分钟，由 variation.seed 决定。同种子完全可复现，换种子换一种走向；第 1 天的作息不浮动，保证 Demo 时刻。

## 策划热改与数据

页头面板默认收起。编辑/导入只改草稿，点击「应用到当前世界」才生效；面板不自动暂停。

| 数据                              | 内容 / 面板入口                                                             |
| --------------------------------- | --------------------------------------------------------------------------- |
| src/data/agents.json              | 人设、作息、性格、需求初值、偏好 / 居民                                     |
| src/data/places.json              | 支持行为、容量、占位行为、坐标 / 地点                                       |
| src/data/relations.json           | 初始关系分数与描述 / 关系                                                   |
| src/data/simulation.json          | 衰减、约定、传闻 / W2 配置                                                  |
| 同文件 behavior / activityMinutes | 心情和社交收益、继续评分、满座扣分、活动时长、排队与偶遇冷却 / 同一规则面板 |
| 同文件 variation                  | 随机种子与第 2 天起的作息浮动分钟 / 同一规则面板「每日变化」                |

应用保留时间、位置、已出发路线、纸条额度/到期及未改需求和关系值。改过的需求初值赋给当前值；行为修改后下一 tick 重选；容量立即重新分配，追加 meta 摘要。非法 JSON、缺字段、负容量、错误引用、增删实体 ID 或破坏有效纸条能力都拒绝，原世界不变。

「导出草稿 JSON」下载 agents / places / relations / rules 合包；再粘贴到 JSON 区、校验载入、应用即可往返。将四字段分别写回上表文件后运行测试/构建。刷新恢复源码配置，普通重开沿用已应用配置。旧合包缺少的规则字段，载入时按内置默认补齐，已有取值保留。

作息用 HH:mm，可跨午夜，重叠按第一条生效。改数据会改变故事时刻，固定演示前先恢复内置草稿、应用并重开。Demo 仍依赖内置 ID/时刻，不保证任意改内容后固定口播有效。

## 评审长跑与回放

1. 「评审复盘」→「一键评审长跑」，用当前已应用配置的副本从 D1 11:40 开新局，关闭 Demo/纸条弹层；期间锁热改与普通时钟。
2. 分片真实执行 1800 tick，可暂停/续跑，结束停在 **D2 17:40**。日常 ×1 的现实 30 分钟 = **1800 游戏分钟 = 30 小时 = 1.25 天**，加速计算不用现场等半小时。
3. 一页纸自动给统计及 6 条样本；点「回看这一刻」同步地图、需求、目标、关系与日志。支持播放/暂停、拖动、输入分钟与 ×1/×2/×8；**回放 ×1 每秒 10 游戏分钟**。
4. 导出本局 JSON，可重置后或另一台相同版本原型导入；分片重算核对事件/快照，错误版本、缺帧、篡改拒绝。回放只读，退出回到导入前世界。
5. 报告可复制/导出 Markdown。全量归档每页 20 条；右侧仍保留 240 条、最多显示 70 条。

只保留最近一局，新长跑前先导出。完成后可继续普通旁观，封存局不变；放弃半局不发布完整档案。现场可直接「加载样例局」：[局 JSON](./public/fixtures/review-run.json)、[报告](./public/fixtures/review-report.md) 会随构建复制到 dist/fixtures。

当前 **little-universe-w4.3** 样例：**373 条全量日志、152 条生活事件、27 次冲突、16 条传闻、61 份快照**。全量密度 **12.43**，生活事件密度 **5.07 条/游戏小时**。生活事件包含偶遇/入座、冲突、传闻、纸条，排除目标/移动/热改/system；不是独立故事链或趣味质量评分。自然疏远的关系对分钟也不是故事数。

旧 w4.1 / w4.2 局不兼容，请重新生成。当前支持固定起点的 1～1800 分钟局，最大 16 MB / 30000 事件；不是通用接续存档。

## 限制与边界

- 页面关闭不继续模拟；普通后台补算最多 720 游戏分钟，暂停不补算。长跑后台节流只延长耗时。
- 无战斗、经济、四季、恋爱、多人、语音、过场、视频剪辑、云端、后端存档或多局管理。未做新加坡玩家化或手机玩法循环。
- 部分效用分数/需求衰减仍是代码常量；本次开放与恢复/保持目标相关的配置。合法极端参数也可能失衡。
- App/CSS、PlannerPanel 的拆分及 ESLint/CI 尚未做；电话标签仍触发模板，Demo 有固定场景依赖。
- VITE*USE_LLM=false 仅占位，设 true 也无模型请求。.env 和 .env.\* 已忽略（保留 example）；\*\*密钥不能放入会打包进前端的 VITE*\* 变量\*\*。
- 当前规则见 [ARCHITECTURE.md](./ARCHITECTURE.md)，测试与证据见 [VALIDATION.md](./VALIDATION.md)。
